# 路线图

## M0 — 模块化框架（本次）

- [x] Node 22.12+、严格 TypeScript、ESM 与锁定依赖
- [x] 来源、分析、规则、通知、存储、时钟、摘要、事件接口
- [x] 按目标查询与去重、检查点 revision、原子提交合同
- [x] 半小时调度策略、08:00 前一天摘要窗口、来源链接
- [x] 通知领取、未知结果隔离、显式恢复合同
- [x] 安全模拟、行为测试、分层依赖检查、CI 与维护文档
